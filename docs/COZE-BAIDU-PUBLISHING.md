# 将短剧行情监控 Agent 发布到扣子或百度

更新日期：2026-08-16

## 先明确迁移方式

Hermes 版本继续作为能力与运行规则的权威源。扣子或百度平台负责对外展示、对话入口和平台内工作流，不直接搬运 Hermes 的本地运行环境。

对应关系如下：

| Hermes | 平台侧配置 |
| --- | --- |
| `SOUL.md` 的角色、边界、输出规则 | 角色指令 / 人设与回复逻辑 |
| 搜索、网页读取、榜单整理工具 | 插件、工作流节点或自定义 API / MCP |
| 每日监控计划 | 定时触发器或外部定时任务 |
| 历史快照、报告 | 知识库、数据库或对象存储 |
| 飞书入口 | 平台发布渠道，或继续由 Hermes 飞书 Bot 承接 |
| API Key | 平台密钥管理，不写入提示词和前端 |

## 推荐选择

- 课程演示优先选扣子：创建、调试、生成公开体验入口较快，适合先完成可访问的智能体页面。
- 正式的中文企业应用优先评估百度千帆 Agent 开发平台：支持自主规划 Agent、工作流 Agent、知识库、数据库、API/SDK 和多渠道发布。
- 当前最佳架构是“双层”：Hermes 负责真实监控任务，平台智能体负责接收请求、展示结果；后续通过受保护 API 连接二者。

## 扣子操作步骤

1. 登录 `https://www.coze.cn/`，进入工作空间。
2. 创建智能体，名称使用“短剧行情监控 Agent”。
3. 将 Hermes Profile 中的角色定位、证据分级、禁止伪造和输出结构迁入“人设与回复逻辑”。
4. 第一版先配置联网搜索、网页读取和表格/文档输出能力；不要在平台提示词中放 DeepSeek、Gemini、飞书或其他服务密钥。
5. 将任务拆为工作流：输入监控范围 -> 多源采集 -> 标准化 -> 交叉验证 -> 趋势判断 -> 生成报告。
6. 用同一测试问题运行一次，核对来源链接、数据日期、不确定性标注和结论是否一致。
7. 点击“发布”，至少选择公开体验或 API 渠道。公开分发可能需要平台审核。
8. 保存公开链接、首页截图和一次成功运行截图，作为关卡材料。

注意：发布后的用户调用通常会消耗开发者侧额度，应设置调用预算、告警和停止策略。

## 百度操作步骤

1. 登录百度千帆 Agent 开发平台，进入 AppBuilder。
2. 创建“自主规划 Agent”；如需要固定的日报管线，则创建“工作流 Agent”。
3. 配置应用名称、头像、角色指令、开场白和推荐问。
4. 添加百度 AI 搜索等组件，并为可复核数据建立知识库或数据库。
5. 在右侧预览区运行完整测试；工作流版本必须从开始节点到结束节点全部通过。
6. 点击“发布”，可选择网页版、应用广场、百度搜索、微信公众号、微信客服、企业微信、网站嵌入或 API/SDK 等渠道，具体以账号控制台显示为准。
7. 保存公开体验链接与运行证据。控制台调试、公开 Demo 和 API 调用都会消耗模型额度。

## 验收测试

统一使用以下任务：

> 生成今日海外短剧行情试运行报告，列出新上榜、持续上升和跨源共振作品，给出三条行动建议；所有事实必须标注来源、日期和证据等级，缺失数据必须明确说明。

通过标准：

- 页面无需开发者账号即可打开，或明确标注为“链接可访问”。
- 至少返回一个可核查来源链接，且日期与指标口径清楚。
- 不把估算值写成官方值，不用单一来源下确定性结论。
- 运行失败时给出数据缺口，不编造榜单。
- 密钥只保存在服务端或平台密钥管理中。
